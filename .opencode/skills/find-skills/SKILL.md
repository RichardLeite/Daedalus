# Find skills

Use the right skill without loading everything.

## Procedure

1. Read the task and identify the phase: discovery, planning, implementation,
   review, testing, release.
2. List candidate skills by ID and description.
3. Pick the smallest set that covers the phase.
4. Load one skill at a time.
5. After loading, follow the skill and do not restate it.
6. Unload or ignore skills that no longer apply.

## Rules

- Do not load every skill.
- Prefer a specific skill over a general one.
- Do not duplicate a skill's instructions in the answer.
- If no skill fits, proceed with the global rules.
- Report missing skills instead of inventing one.

## Output

Selected skills, why, and the next action.
