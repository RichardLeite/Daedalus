Prepare a pull request for: $ARGUMENTS

Load the `pr` skill.

1. Confirm the branch.
2. Run the project's tests and linters.
3. Write what changed, why, evidence, risks, and rollback.
4. Create the PR with `gh pr create`.
5. Report the URL and checks.

Do not merge or approve. Do not force-push.
