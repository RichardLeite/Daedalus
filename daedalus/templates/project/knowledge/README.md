# Project knowledge

Durable project documentation lives here. Keep session notes out of this
directory; they belong in the agent's memory system when one is configured.

## Directories

- `decisions/` — architecture decision records.
- `specs/` — feature and change specifications.
- `plans/` — temporary implementation plans. Ignored by Git.

## Before implementing

1. Read the relevant spec or decision.
2. Read the project `AGENTS.md`.
3. Follow the project's existing patterns.
4. Run the project's tests and `daedalus validate` before opening a pull request.
